# NalApps Admin UI Kit v2.0.1 — Design Tokens

## 기본 색상
- Primary: `#2563EB`
- Primary Dark: `#1D4ED8`
- Primary Deep: `#1E3A8A`
- Primary Soft: `#EFF6FF`
- Background: `#F6F8FC`
- Panel: `#FFFFFF`
- Border: `#DBE4F0`
- Text: `#1E293B`
- Muted: `#64748B`

## Typography
- Font family: `Pretendard Variable`, `Pretendard`
- Body / form / table body: `400`
- Navigation / button / form label: `550~600`
- Section heading / panel heading: `600~650`
- Page title / KPI primary value: `700`
- `800~900`은 일반 관리자 UI에서 사용하지 않습니다.
- 웹폰트는 Pretendard 공식 안내의 jsDelivr variable dynamic subset을 사용하고, 로딩 실패 시 시스템 폰트 스택으로 fallback 합니다.

## 상태 색상
Success/Warning/Danger는 **실제 상태 표현에만** 사용합니다. KPI 장식, 일반 버튼, 섹션 포인트에 임의로 초록·주황·빨강·보라를 사용하지 않습니다.

## 원칙
1. 기본 인터페이스는 Blue / Navy / Soft Blue / Neutral Gray 네 계열로 통일합니다.
2. Primary action만 진한 파랑을 사용합니다.
3. 카드마다 다른 장식색을 쓰지 않습니다.
4. 배경 효과는 약하게 유지하고 콘텐츠 가독성을 우선합니다.
5. 글자 굵기로 모든 계층을 표현하지 않고 크기·간격·색상과 함께 계층을 만듭니다.
