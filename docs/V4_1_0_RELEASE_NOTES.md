# NalApps WordPress Plugin Standard v4.1.0

## Verdict

`PASS_READY_FOR_V4_1_0_RELEASE`

v4.1.0 extends the v4 automated plugin platform with a common maintenance and recovery runtime while preserving the immutable v4.0.0 baseline.

## Added

- Safe plugin code rollback with pre-update package backup.
- Pre-update and pre-import data snapshots kept outside the plugin directory.
- Explicit, profile-driven data export/import contract for options, site options and owned post types.
- Sensitive credential-like option names are rejected from automatic portability contracts.
- Default uninstall policy remains data preservation.
- Explicit `delete_all` uninstall mode for products that intentionally opt in to complete owned-data removal.
- Secret-redacted system information and maintenance diagnostics.
- Common maintenance UI/runtime generated by the canonical NalApps scaffolder.
- Maintenance contracts wired into self-test, standard audit and release gates.

## EDD updater correction

- The generated EDD paid updater now treats the EDD Software Licensing `package` field as the canonical WordPress installation URL.
- Legacy `download_link` is retained only as a compatibility fallback.
- WordPress update transient and the internal updater consume the same resolved package URL.
- Regression coverage prevents reintroduction of the empty-package update failure.

## Final automated verification

The final candidate passed:

- canonical standard audit
- free / EDD paid / full-capability scaffold self-test
- boundary, negative, privacy and updater regression tests
- public repository safety gate
- official WordPress Plugin Check for free and EDD paid representatives
- Composer dependency security audit
- PHP syntax
- WordPress Coding Standards / PHPCS
- PHP 7.4 / 8.1 / 8.3 / 8.4 / 8.5 compatibility matrix
- release provenance checks

## Release policy

`VERSION` is bumped only after all implementation and automated quality gates pass. Existing tags remain immutable.
