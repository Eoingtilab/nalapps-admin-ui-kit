# 절대 금지사항

1. UI Kit을 보고 "비슷하게" 재해석하지 않는다. 제공 CSS/Adapter/클래스를 먼저 사용한다.
2. 일반 상태에 주황·노랑·보라·초록을 장식색으로 섞지 않는다.
3. Dashboard 카드마다 서로 다른 컬러를 임의로 부여하지 않는다.
4. 플러그인 관리 홈에 상단 플러그인 타이틀/내부 내비게이션/페이지 헤더를 누락하지 않는다.
5. 기존 WordPress `.wrap` 위에 CSS만 덮고 완료했다고 판단하지 않는다.
6. UI 변경을 위해 저장/발행/API/프런트 동작 코드를 수정하지 않는다.
7. 다른 관리자 화면에 Kit CSS를 전역 로드하지 않는다.
8. 큰 고정 높이로 빈 회색 영역을 만들지 않는다.
9. 외부 플러그인의 버튼 CSS가 NalApps primary 색을 덮도록 방치하지 않는다.
