# Components

- `.nalapps-shell`: 최대 폭 및 페이지 여백
- `.nalapps-global-nav`: 플러그인 상단 브랜드/내부 메뉴
- `.nalapps-brand*`: 플러그인 브랜드 제목
- `.nalapps-nav`: 관리 홈/목록/새로 추가 등 내부 내비게이션
- `.nalapps-page-header`: 페이지 제목/설명
- `.nalapps-kpi-grid`, `.nalapps-kpi-card`: 관리 홈 요약
- `.nalapps-panel`: 설정/작업 섹션
- `.nalapps-grid-*`: 폼 레이아웃
- `.nalapps-notice`: 일반 안내. 상태는 `.is-success/.is-warning/.is-danger`

관리 홈의 KPI 카드는 콘텐츠 양에 맞춰 자연 높이를 사용합니다. 의미 없는 `min-height`로 큰 빈 영역을 만들지 않습니다.
