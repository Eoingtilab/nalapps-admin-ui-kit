## 설치 및 시작

1. 공식 배포 ZIP을 사용합니다.
2. WordPress 관리자 → 플러그인 → 새 플러그인 추가 → 플러그인 업로드에서 설치합니다.
3. 활성화 후 제품별 설정 안내를 따릅니다.
4. Composer runtime dependency가 있는 제품은 GitHub Source ZIP이 아니라 production dependency가 포함된 Release Asset을 사용합니다.
